Zirco is a hobbyist compiler for a statically-typed, C-like programming language.

It has an ecosystem of supporting tooling, as well:

- [Homepage](https://zirco.dev)
- [Playground](https://play.zirco.dev)
- [Book](https://book.zirco.dev)
- [zrc Compiler](https://github.com/zirco-lang/zrc)
- [zircon Toolchain Manager](https://github.com/zirco-lang/zircon)
