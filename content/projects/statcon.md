statcon is a simple, declarative, and function-composition-based Gatus configuration generator.

It was developed because statcon's configuration YAML is long and unmaintainable, and I wanted to use function composition and plugins to generate it.

This is heavily inspired by my prior work on [gin](./gin), a similar project for nginx.

Although I no longer deploy nginx, this project later inspired [statcon](./statcon).
